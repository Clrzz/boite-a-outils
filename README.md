# Boîte à outils de Crz

Tableau de bord PC (températures, nettoyage, gaming, coffre-fort, soundboard, Stream Deck…).

- `boite_a_outils.pyw` : le programme (double-clic pour lancer, Python 3 requis)
- `com.crz.capteurs.streamDeckPlugin` : le plugin Stream Deck
- `version.json` : la dernière version ; la boîte à outils le lit pour se mettre à jour toute seule
